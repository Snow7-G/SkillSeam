模拟 agent 挑选 skill 的真实过程，找出你整套 skill 里「谁抢了谁的活」。 纯静态页面：API key 只存在你的浏览器 localStorage，请求从浏览器直达模型端点，不经过任何服务器。

1 · 输入

冲突判定需要「应选技能」标注；没标注的任务 agent 会给出选择与一致率，由你人工判断选得对不对。

2 · 模型端点（BYOK）

采样次数越多结论越稳，费用与耗时线性增加。判定规则：5 次采样至少 4 次同结果为「稳定」；应选标注的任务若稳定选中其他技能即「截胡」。自动生成会先让模型挑出最易混淆的技能对，再为每对双向生成边界问法——生成后建议人工过一遍再模拟。
